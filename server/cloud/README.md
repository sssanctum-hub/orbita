# Переход на Cloud Functions + YDB

Адаптер ydb-store.mjs использует Document API и короткоживущий IAM-токен функции, без статических ключей. Условные записи нужны для атомарной регистрации и контроля ревизий между устройствами. Таблица создаётся по table.json. База и таблица не должны быть публичными.

Это только адаптер хранения. Обработчик Cloud Functions, доставка подтверждений почты, восстановление доступа, перенос фотографий в закрытое Object Storage и проверка развёртывания ещё не завершены. SQLite-прототип нельзя запускать с локальным диском функции: данные будут теряться.

Бесплатные лимиты не гарантируют нулевой счёт. Перед созданием нужны ограничения нагрузки и согласованные роли сервисного аккаунта.
